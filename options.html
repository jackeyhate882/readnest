阅巢 ReadNest 设置

所有设置与文章都保存在本机浏览器，不会上传。

划词翻译

选中文字后点「译」，或右键里复制到别处翻译。国内网络建议选第三个，用 DeepSeek 等 API。

阅读外观

「纸感」用衬线字体和暖纸底色，接近 alexwang.ai 这类博客的排版；「跟随原站风格」会在抓取时记录原文的字体和配色（仅标签页抓取的文章有）。阅读页右上角的圆形按钮也能快速切换。

AI 概述

阅读页顶部会显示一段概述。配好上面的 OpenAI 兼容 API 后由模型生成；没有 Key 时自动退化为本地摘录（按词频挑要点）。

抓取行为

像 Substack、微信公众号等在浏览器里能正常打开的页面，通常需要用后台标签页方式抓取。

怎么用

  1. 在任意网页点浏览器右上角的阅巢图标 →「抓取当前页面」；或把链接粘到书库输入框。
  2. 阅读页里选中文字，浮出的工具条可以高亮（四种颜色）、写笔记、划词翻译。
  3. 点右上角「标注」能看到全部高亮和笔记；「⋯」里可以导出 Markdown、重新抓取正文。
  4. 快捷键：Alt+Shift+S 保存当前页；阅读页 N 标注栏、T 目录、Esc 关闭浮层。
